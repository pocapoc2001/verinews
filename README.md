# VeriNews

Geometric-NLP pipeline and dashboard for OSINT narrative analytics: automated news
aggregation, similar-news detection by topic and event, abstractive summaries, and a
**Triangulated Veracity Score (TVS)** that expresses how well a narrative is corroborated
by independent sources.

Code accompanying the paper *Similar News Detection Based on Topic and Event: The VeriNews
Engine for OSINT Narrative Analytics* (Alexandru Ciobanu, Răzvan Păroiu).

> The TVS measures verification confidence, **not** truth: a high score means the summary
> is faithful to several mutually consistent, independent sources. The benchmark in
> `experiments/` shows that it does not separate claims rated true from claims rated false
> by fact-checkers, because a well-debunked falsehood is itself well corroborated.

## What is in this repository

| Part | Files |
|---|---|
| Pipeline | [Alex1.py](Alex1.py) (ingestion, enrichment, topic model, summaries, TVS, export), [verinews_common.py](verinews_common.py) (shared helpers, canonical TVS), [streaming_topic_model.py](streaming_topic_model.py) (incremental clustering) |
| Dashboard | [app/](app), [components/verinews/](components/verinews), [hooks/](hooks), [lib/](lib) — Next.js 15 / React 19 |
| Benchmark | [experiments/](experiments) — fact-checked claims, frozen evidence, baselines, parameter study, results |
| Tests | [tests/](tests) — pytest (no network, no models) and vitest (TypeScript/Python TVS parity) |

**Not included:** the scraped article bodies. They are the publishers' text, so the evidence
bundles in `experiments/evidence/` keep titles, URLs, publisher domains, the extractive
summary, the claim sentences and every similarity matrix, but not the article text
(`"article_text_removed": true`). The dissertation corpus and the paper sources are not
part of this repository either.

## Setup

```bash
pip install -r requirements.txt     # backend (Python 3.10+)
npm install                          # dashboard (Node 18+)
```

## Running

```bash
python Alex1.py                                  # full batch: scrape → NLP → clusters → summaries → TVS → export
python Alex1.py -t "Gold Market Trends" -t "Bitcoin Price Analysis" --max-articles 15
python Alex1.py --stream                         # incremental update (partial_fit); needs one batch run first
python Alex1.py --diagnose                       # ingestion self-test
npm run dev                                      # dashboard at http://localhost:3000
```

The dashboard reads `public/osint_output.json`, which the pipeline writes; run the pipeline
once (or start a job from the dashboard's "Run live ingestion" panel) before opening it.
Jobs are only accepted from localhost unless `VERINEWS_ALLOW_RUN=1` is set.

## Tests

```bash
pytest -q          # backend: domains, decoder, labels, quality report, TVS, baselines, metrics
npx vitest run     # lib/tvs.ts parity against a fixture generated by the Python implementation
npm run lint && npx tsc --noEmit
```

## Reproducing the benchmark

`experiments/ground_truth/claims.csv` holds 40 claims with published Snopes verdicts
(20 true, 20 false), harvested through the ClaimReview vocabulary and split once into
24 calibration and 16 held-out claims; 36 retrieved enough coverage to be scored.
`experiments/results/` contains the tables and the summary reported in the paper.

```bash
python experiments/sweep_parameters.py     # parameter study (Table III of the paper)
python experiments/evaluate.py             # comparison with the other methods (Table IV)
```

- The parameter study reads only the frozen similarities and domains, so it reproduces
  exactly.
- In the comparison, the TVS and baselines B4–B7 are recomputed exactly from the bundles.
  B1 probes the publishers' websites live, and websites change. B2 and B3 read the article
  bodies, which are not redistributed, so their rows cannot be reproduced from this copy;
  the reported values are in `experiments/results/`.
- Both scripts **rewrite** `experiments/results/`. Run them on a copy if you want to keep
  the reported numbers side by side.
- To rebuild the evidence from scratch (network access; news coverage changes over time, so
  the numbers will differ): `python experiments/build_evidence.py --redo --refresh`.

## Triangulated Veracity Score

`TVS = clamp(F1 × F2 × F3, 5, 99)`, where **F1** is semantic fidelity (mean cosine similarity
between the summary and its three closest sources, mapped to 30–100), **F2** a domain-diversity
multiplier (0.60 for a single source up to 1.00 for five or more independent sources) and
**F3** inter-source coherence (mean pairwise source similarity mapped to 0.70–1.00). The
canonical implementation is `tvs_from_evidence` in [verinews_common.py](verinews_common.py);
[lib/tvs.ts](lib/tvs.ts) mirrors it, with automated parity tests between the two.

## Outputs of a pipeline run

- `public/osint_output.json` — the dashboard export (topics, per-article similarities,
  coherence matrices, corpus quality report). Override the directory with `VERINEWS_PUBLIC_DIR`.
- An enriched Excel corpus, a text dossier with TVS breakdowns and two Plotly visualizations
  in the output directory.
- `model_state/` + `stream_corpus.csv` — persisted streaming state (created by `--stream`).

## Environment variables

| Variable | Purpose |
|---|---|
| `VERINEWS_PUBLIC_DIR` | directory that receives `osint_output.json` (default `public/`) |
| `VERINEWS_PYTHON` | interpreter used by the run-from-UI route (default `.venv/…/python`) |
| `VERINEWS_ALLOW_RUN` | `1` allows starting jobs from a non-localhost host |
